# OCR Lab

Accessible OCR application for macOS and Windows, designed to work well with screen readers.

Supports multiple OCR engines: Tesseract, Surya, Surya 0.2, Apple Vision (macOS), and VLM-based backends.

## Download

See the [releases page](https://github.com/lcasarotti/OCRLab/releases) for the latest build.

## Acknowledgments

OCR Lab builds on the following open-source projects:

- **[Surya](https://github.com/VikParuchuri/surya)** — multilingual document OCR engine based on deep learning, developed by Vik Paruchuri. Surya 0.2 adds a VLM-based recognition pipeline for higher accuracy on complex layouts.
- **[Tesseract OCR](https://github.com/tesseract-ocr/tesseract)** — open-source OCR engine originally developed at HP and now maintained by Google, with support for over 100 languages.
